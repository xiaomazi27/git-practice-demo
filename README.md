# Git 学习实践笔记
## Git 学习笔记
1. Git 是分布式版本控制工具。
2. 核心作用：管理代码版本、回溯、协作。
3. 常用命令：git init、git add、git commit、git push、git log。

## 实践流程
1. 安装 Git 并配置用户名、邮箱
2. 创建文件夹，git init 初始化仓库
3. 编写代码并多次提交
4. 完善 README 文档
