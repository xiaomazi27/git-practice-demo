# Git 学习实践笔记
## Git 学习笔记
1. Git 是分布式版本控制工具。
2. 核心作用：管理代码版本、回溯、协作。
3. 常用命令：git init、git add、git commit、git push、git log。

## 实践流程
1. 安装 Git 并配置用户名、邮箱
2. 创建文件夹，git init 初始化仓库
3. 编写代码并多次提交
4. 完善 README 文档

## 遇到的问题及解决方法 
1. 问题：命令输入错误，Git Bash 卡住 解决：按 Ctrl+C 中断，重新输入正确命令 
2. 问题：不明白 commit 是什么 解决：commit 就是保存一个版本，方便以后回溯
3. 问题：不会粘贴命令 解决：shift+insert粘贴或者按鼠标中间的滚轮
4. 问题：git commit 时报错，提示 nothing to commit 解决：说明没有修改文件，必须先修改代码或文档，再执行 git add . 才能提交 
5. 问题：运行Python代码时报错，提示 no module named 'tkinter' 解决：这是Python缺少图形库，重新安装Python时勾选“Add to PATH”并安装完整版本

## Git 学习心得
我之前从来没有接触过Git，这次实践让我打开了版本管理工具的大门。从最开始安装 Git、配置用户名和邮箱，到一步步创建仓库、提交文件，每一步都充满新鲜感，也让我深刻体会到 Git 的强大与实用。
在学习过程中，我从完全陌生到逐渐熟练使用git init、git add、git commit等核心命令，明白了每一次提交都是一次代码的 “存档”，可以清晰记录所有修改过程，再也不用担心代码误删、覆盖或找不到历史版本。同时，我也学会了在项目中逐步完善功能、规范提交信息，培养了良好的代码管理习惯。
这次实践让我掌握了 Git 的基础操作，还让我理解了版本管理在编程学习和项目开发中的重要意义。它不只是一个工具，还可以提升学习效率、保证代码安全。未来在编程学习和课程项目中，我一定会坚持使用 Git 进行代码管理，不断熟练掌握更多功能，为后续的专业学习打下扎实基础。
